# Upload SafeOS 4 to the Development Branch

Repository: `abasit0315-cell/hse-quicktools`
Branch: `safeos-v4-development`

1. Keep GitHub Pages configured to deploy from `main`.
2. Open the repository and switch the branch selector to `safeos-v4-development`.
3. Select **Add file → Upload files**.
4. Extract the ZIP package locally.
5. Open the extracted `SafeOS_v4_Development_Staging` folder.
6. Upload all files inside the folder directly to the repository root. Do not upload the outer folder or the ZIP itself.
7. Allow GitHub to replace matching files.
8. Commit with: `Stage SafeOS 4 development foundation`.
9. Do not merge into `main` yet.

The branch is a development build. The live production site must remain on `main` until multilingual, PDF, QR, mobile and security release tests pass.
